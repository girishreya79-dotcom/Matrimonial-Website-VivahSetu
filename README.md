# Matrimonial Website - VivahSetu

VivahSetu is a matrimonial website where users can create and manage profiles, discover suitable matches, search for partners, connect through messaging, and interact through a simple, user-friendly platform. It also includes admin features for managing users and removing fake profiles.

## Features

### User Features
- User registration and login
- Profile creation and profile completion
- Manage personal and partner preferences
- Search for suitable partners
- View user profiles
- Send and receive messages

### Admin Features
- Admin login
- View registered users
- Manage user accounts
- Remove fake or unwanted profiles

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- PHP
- MySQL

## How to Run

1. Install and open XAMPP.
2. Start **Apache** and **MySQL** from the XAMPP Control Panel.
3. Place the project folder inside the `htdocs` folder.
4. Open **phpMyAdmin** and create the required database and tables.
5. Make sure the database connection settings in the PHP files are correct.
6. Open your browser and go to:

   `http://localhost/Matrimonial-Website-VivahSetu/`

7. The website will run locally on your computer.

## Database

The project uses MySQL to store user registration details, profile information, preferences, and messages.

## Project Purpose

This project was developed as a web development project to create a simple matrimonial platform with user and admin functionality.
